# Cara - E-Commerce Platform

A responsive, lightweight e-commerce platform interface built to demonstrate front-end shopping functionality.

## Features
- **Responsive Navigation**: Header with interactive cart counter.
- **Product Catalog**: Clean card grid layout displaying product titles, brands, and prices.
- **Interactive Cart**: Functional JavaScript logic for adding items to the shopping cart.

## Tech Stack
- **HTML5**
- **CSS3**
- **JavaScript (Vanilla)**
